# マラソンペースプランナー 金沢マラソンスペシャル

Marathon Pace Planner (Kanazawa Marathon Special)

区間ごとのペースを入力して、ネットタイム・グロスタイム・5kmラップ・1kmごとの通過タイムなどを計算する、マラソンのペース計算ツールです。

**▶ アプリを開く: https://isomeday.github.io/marathon-pace-planner2026/**

（ここに画面のスクリーンショットを1枚入れると、伝わりやすくなります）

## できること

- 区間ごと（1km単位）のペースを入力して、ゴールタイムを計算します
- 号砲時刻・スタートまでの時間から、ゴール時刻とグロスタイムを出します
- 公式距離とランニングウォッチの距離のずれ（調整距離）を考慮した場合と、考慮しない場合の両方を表示します
- 区間ペースのグラフ、5kmラップのグラフと表、1kmごとの通過表を表示します
- ネットとグロスの平均ペース（公式距離42.195kmあたり）を表示します
- 前半・後半のタイムと、ネガティブ／ポジティブスプリットを表示します
- 時刻や時間は、コロン(:)なしの数字だけ（例: 8:30 は 830）でも入力できます
- パソコンでもスマートフォンでも使えます

## 使い方

1. 上のリンクを開きます（インストールや登録は不要です）
2. 左側（スマートフォンでは上側）の「レース設定」と「区間ペース」を入力します
3. 画面右側の数字とグラフが、入力に合わせて変わります

入力欄の意味は、画面の「入力の説明」ボタンで確認できます。

初期値は、過去の金沢マラソン出場の経験値をもとに、サブ４あたりを想定して入れています。ご自身の設定に変更してお使いください。

## 無料・登録不要・広告なし

どなたでも無料でお使いいただけます。アカウント登録も広告もありません。

## 入力した値の扱い

- 入力した値は、お使いのブラウザの中（localStorage）にだけ保存されます
- 入力した値を、サーバーなど外部に送ることはありません
- 画面の文字を表示するために、Google Fonts を読み込んでいます（ページを開く際、お使いの端末のIPアドレスなどがGoogleに送信されます）

## ソースコードについて

アプリは、`index.html` の1ファイルだけで動いています（HTML・CSS・JavaScript）。外部のライブラリは使っていません。

ブラウザで右クリックして「ページのソースを表示」を選ぶと、中身を確認できます。このリポジトリの `index.html` と同じものです。

## ご注意

- 非公式の、個人が作ったツールです。金沢マラソンの主催者・運営とは関係ありません
- 計算結果は目安です。実際のレースの結果や、安全を保証するものではありません。ご利用は自己責任でお願いします
- 時間は、1秒未満を切り上げて表示しています（公認ロードレースの扱いに合わせています）
- 調整距離は、設定した距離のずれの割合（調整距離 ÷ 42.195km）を、ネットタイムに上乗せして計算しています
